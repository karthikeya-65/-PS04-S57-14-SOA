1. Centralized JWT Auth & Header Propagation:

The API Gateway validates JWT signatures and injects verified identity claims downstream (X-User-Id, X-User-Username, X-User-Roles), freeing microservices from redundant authentication.

2. OpenFeign Inter-Service RPC:

Booking Service invokes declarative OpenFeign clients to query Room Service for live unit inventory and User Service for guest profile resolution without hardcoded IP dependencies.

3. Database-per-Service Isolation:

User DB, Room DB, and Booking DB are strictly segregated schemas (H2 in dev, MySQL in prod), guaranteeing zero tight coupling and true microservice autonomy.

4. Concurrency & Overlap Mathematical Engine:

Active bookings overlap if (check_in < req_checkout AND check_out > req_checkin). Total overlapping units are subtracted under transaction isolation to eliminate race conditions and double bookings.
